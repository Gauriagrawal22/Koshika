## Media Specifications
- **Video Codec**: H.264 / AVC (High Profile)
- **Audio Codec**: AAC-LC, Stereo, 48 kHz, 192 kbps
- **Resolution**: 1920x1080 (16:9 widescreen) or 1280x720
- **Frame Rate**: 30 fps or 60 fps
- **Fallback**: When an MP4 file is not deployed on disk, KOSHIKA's built-in interactive animated visual explainer engine automatically takes over, synchronizing clinical animations with localized subtitles and timecodes.
